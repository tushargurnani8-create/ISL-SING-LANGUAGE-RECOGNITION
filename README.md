# Indian Sign Language Recognition

## 📌 Project Overview

This project focuses on recognizing Indian Sign Language (ISL) gestures using Machine Learning and Computer Vision.

The system processes sign language images/frames and uses a deep learning model to classify different ISL signs.

## 🚀 Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- MediaPipe
- NumPy
- Scikit-learn
- Jupyter Notebook

## 🧠 Model

The project uses a deep learning image classification approach for recognizing Indian Sign Language gestures.

## 📊 Dataset

The model is trained using an Indian Sign Language dataset containing multiple sign classes.

## 📁 Project Files

- `TUSHARCODER.ipynb` — Jupyter Notebook containing the complete implementation, training and evaluation code.

## 🎯 Objective

The main objective is to develop an automated system that can recognize Indian Sign Language gestures and convert them into understandable text.
